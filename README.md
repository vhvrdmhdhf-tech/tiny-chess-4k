A chess engine that fits in 4 KB of Python: main.py (3,431 bytes) unpacks and runs an original alpha-beta engine with iterative deepening, a transposition table, null-move pruning, quiescence search, MVV-LVA move ordering and tapered piece-square evaluation, searching a fixed 160,000 nodes per move.

## Run it

```sh
MAKEFUN_ENV_URL=<env-url> python3 main.py
```
